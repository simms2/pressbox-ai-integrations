# Public Pressbox News Wire in Gemini Apps

Google documents custom MCP connections for eligible consumer accounts. Actual Pressbox acceptance in this consumer client remains untested; no directory listing or Google endorsement is claimed.

## Eligibility and setup

Google currently requires users to be 18 or over, in the US, using a personal Google Account and English, with Keep Activity enabled. Work/school accounts are excluded. Review Google's activity/privacy choices before making changes.

1. In the Gemini web app, open Settings → Connected Apps (sometimes under Personal Intelligence).
2. Under Custom apps, add the public server URL: `https://pressbox.com/mcp`.
3. Choose Next and review the provider's prompts. This public News Wire needs no Pressbox password, Auth0 client secret or private workspace access.
4. Once connected, use `@` to select the custom app and ask for published Pressbox news with source links and dates.

This endpoint searches public releases and newsrooms only. It cannot publish, send emails, buy services or read a private workspace. It is separate from `https://agent.pressbox.com/mcp`, whose private-account setup is not covered here.
