# Pressbox in Perplexity

Use the public News Wire to research published announcements. This setup cannot read private workspaces, edit releases, send messages or buy distribution.

1. Open **Plugins → Add custom → Connector → Add MCP connector**. Some accounts show **Customize → Connectors** instead.
2. Select **Remote**. Name it **Pressbox News Wire**.
3. Enter `https://pressbox.com/mcp`, choose **None** for authentication and **Streamable HTTP** for transport.
4. Review Perplexity's acknowledgement, then add the connector.
5. Ask: “Use Pressbox News Wire to find a published announcement about technology. Open one result and give its original source URL.”

Account availability and organization permissions apply. Setup and runtime acceptance in Perplexity are not yet verified for Pressbox. This is a custom connection, not a curated listing or a guarantee of citations in other users' answers.

Private OAuth connection requires a separately approved Pressbox client; do not reuse another platform's credentials.
